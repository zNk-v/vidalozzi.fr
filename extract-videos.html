Extraction des vidéos

Tes vidéos UGC sont stockées dans IndexedDB (uniquement dans ton navigateur sur cet ordinateur). Pour qu'elles s'affichent en ligne pour tes visiteurs, il faut les sortir d'ici et les remettre dans assets/videos/.

  1. Clique sur chaque "Télécharger" ci-dessous (un par un, sinon ton navigateur peut bloquer).
  2. Compresse les vidéos lourdes avec HandBrake (preset "Web → Vimeo YouTube HQ 1080p30"). Objectif : <20 Mo par vidéo.
  3. Place les fichiers compressés dans le dossier assets/videos/ du projet, avec exactement ces noms : home-showreel.mp4, ugc-tile-1.mp4, etc.
  4. Redéploie le ZIP — les vidéos s'afficheront pour tout le monde.
Chargement… Si rien n'apparaît, clique sur "Scanner IndexedDB".

Et après ?

Une fois tes vidéos compressées et placées dans assets/videos/, demande-moi le ZIP de déploiement. Le code a déjà été modifié pour charger ces fichiers à la place d'IndexedDB.
